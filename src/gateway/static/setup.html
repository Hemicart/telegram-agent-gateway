Get your Telegram keys

Telegram gives every person their own API keys for apps like this one. It takes two minutes.

  1. Open my.telegram.org in a new tab.
  2. Enter your phone number in international format, e.g. +44 7700 900123.
  3. Telegram sends a code inside the Telegram app (not SMS). Type it on the site.
  4. Click API development tools.
  5. Fill the form. Any values work: App title Agent Gateway, Short name agentgw, Platform Other. Click Create application.
  6. Copy App api_id and App api_hash into the boxes below.
If the site just says “ERROR”, turn off any VPN and try another browser. It’s a known Telegram quirk.
Treat it like a password. It’s stored only on this server’s disk.

Log in to Telegram

  1. On your phone, open Telegram → Settings → Devices.
  2. Tap Link Desktop Device.
  3. Point the camera at this code.
Generating…

The code refreshes by itself. If you use a 2FA password, you’ll be asked for it next.

It arrives in the Telegram app on your other devices first.
Your account has a 2FA password. Enter it to finish logging in.
This is the cloud password you set in Telegram (Settings → Privacy and Security → Two-Step Verification), not the login code. A few wrong tries lock attempts for up to an hour.

Choose what the agent can read

The agent sees only chats in one Telegram folder. Everything else stays invisible to it.

  1. In Telegram, open Settings → Folders (Chat Folders) → Create New Folder.
  2. Name it exactly Agent.
  3. Tap Add Chats and pick the chats one by one.
  4. Pick individual chats only. The Add Chats window also has a Chat types section at the top (Contacts, Non-Contacts, Groups, Channels, Bots). Leave those unticked: each one would let in every chat of that kind, so the server refuses them.
  5. Save, then press Check folder below.

    Connect your agent

    Your agent gets a web address and a secret token. It never sees your Telegram login.

    1. Press Create token. It’s shown once, so copy the block below before leaving this page.
    2. Paste the block into your agent: Claude project instructions, a Grok/ChatGPT custom instruction, or your own agent’s system prompt. For code, put the URL and token in its secrets as GATEWAY_URL and GATEWAY_TOKEN.
    3. Press Test to check that the token works.
